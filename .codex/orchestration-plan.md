## Package controls

- Allowed writes are enumerated per delegation; every other repository path is forbidden. Two concurrent agents never share a write path.

- Test-first tasks must demonstrate the expected pre-implementation failure when the task requires it, then a passing focused command.
- Changes to package constraints require official-version compatibility evidence and coordinator ownership.
- Application errors are distinguished from host/tooling limitations; a command that cannot run is recorded as not run/passed.
