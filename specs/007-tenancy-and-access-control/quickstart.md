# Quickstart — Tenancy specification validation

1. Read `.specify/memory/constitution.md` completely.
2. Read `docs/replatform/product-clarification-register.md` and `clarification-log.md` completely.
3. Read all Feature 007 files and contracts.
4. Read affected Features 001–006 before proposing changes.
5. Do not write application code while `BLOCKING` or `HIGH` product questions remain open.
6. Do not ask the user to choose packages, middleware, database topology or implementation patterns.
7. Verify that every tenant-bound resource has an owner and every action has an authorization result.
8. Verify direct-link, export, report, attachment and download isolation scenarios.
9. Keep the implementation compatible with a Laravel monolith on PHP and MySQL hosting.
