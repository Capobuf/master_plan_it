# Domain glossary

| Term | Definition | Label |
|---|---|---|
| Expense | Container for one or more economic rows for a year and cost center. | VERIFIED CURRENT |
| Expense row | Sole authoritative unit used by totals. | VERIFIED CURRENT |
| Ordinary | Expense kind supporting Estimate, Quote, Actual and optional project/contract context. | VERIFIED CURRENT |
| Plafond | Funding envelope represented as an Expense; its active row amounts define capacity. | VERIFIED CURRENT |
| Estimate | Non-definitive planning phase; negative net forbidden. | VERIFIED CURRENT |
| Quote | Non-definitive quoted phase; negative net forbidden. | VERIFIED CURRENT |
| Actual | Definitive phase; may be negative; cannot be replaced. | VERIFIED CURRENT |
| Active | Row participates in totals. | VERIFIED CURRENT |
| Replaced | Historical superseded row excluded from totals. | VERIFIED CURRENT |
| Cancelled | Historical cancelled row excluded from totals. | VERIFIED CURRENT |
| Extra | Unplanned/out-of-scope ordinary Actual; mutually exclusive with plafond funding. | VERIFIED CURRENT |
| Contract term | Date-bounded economic version with Monthly or Annual billing cycle. | VERIFIED CURRENT |
| Generated contract row | Actual expense row generated once per term/year source key. | VERIFIED CURRENT |
| Project stage | Idea, Proposed, Approved, Deferred, Rejected. | VERIFIED CURRENT |
| Economic position | Dataset combining operating budget, plafond, actual and remaining forecast without counting contracts separately. | VERIFIED CURRENT |
