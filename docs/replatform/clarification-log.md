# Product Clarification Log

| Question ID | Decision | Date | Affected artifacts | Consequences |
| ----------- | -------- | ---- | ------------------ | ------------ |
| Q-001 | Replace the four legacy product roles with three roles. `System Manager` and `vCIO Manager` converge into global `Administrator`; `Client Editor` is renamed `Editor`; `Client Viewer` is renamed `Viewer`. | 2026-08-02 | Constitution; all feature specs; every authorization contract; migration mapping; quickstarts; tests; traceability. | All role matrices and legacy-user mappings must converge on three roles. Administrator retains global scope and does not bypass domain invariants. |
| Q-002 | Tenant lifecycle is `Active`/`Inactive`. Only Administrator may create, deactivate, and reactivate tenants. Permanent tenant deletion is not available. Data, users, attachments, and audit are retained while inactive. | 2026-08-02 | Tenancy feature; data model; tenant-context contract; operations; audit; authorization; risk register. | Deactivation blocks tenant-bound use without destroying history and must be reversible by Administrator. |
| Q-003 | Only Administrator creates, invites, updates, and deactivates Editor and Viewer accounts. A tenant may have multiple Editors and multiple Viewers. | 2026-08-02 | Tenancy spec; user-management screens; authorization matrix; onboarding; migration; tests. | Tenant users cannot administer other users. User membership remains single-tenant for Editor and Viewer. |
| Q-004 | Administrator selects an explicit tenant context and continues to act under the Administrator identity. Impersonation is not part of the product. Every action remains attributed to the Administrator. | 2026-08-02 | Tenant-context contract; audit; screen shell; session behavior; authorization; acceptance tests. | The UI must expose active tenant context and audit must distinguish Administrator actions from tenant-user actions. |
| Q-005 | Viewer receives complete read access to the tenant’s operational data, economic amounts, detail rows, projects, contracts, vendors, cost centers, plafond, attachments, audit, reports, print, and export. Viewer cannot write, administer tenant users, or perform global operations. | 2026-08-02 | All feature authorization contracts; navigation; reporting; export/print; attachments; audit; tests. | Viewer is a comprehensive tenant read-only role, not a dashboard-only role. |
